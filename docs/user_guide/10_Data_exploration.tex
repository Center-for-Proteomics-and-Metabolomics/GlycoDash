\section{Data exploration (optional)}
The data exploration tabs offers various options for simple data visualization.
To create more than one plot, use the \menu{Add a tab +} button in the top-right corner of the box.

To create a plot, take the following steps:

\begin{enumerate}[topsep=0pt, itemsep=0pt]
	\item Choose the type of plot to create: boxplot, scatter plot or histogram.
	\item Optionally, select sample types to exclude from the plot.
	\item Select the variable to be plotted on the $x$-axis.
	\item Select the variable to be plotted on the $y$-axis (not applicable for histograms).
	\item Optionally, choose a variable to facet by.
	\item Optionally, choose a variable to color by.
\end{enumerate}

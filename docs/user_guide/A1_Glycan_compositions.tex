\subsection{Human IgA}
\subsubsection{IgA1 O-glycans}
The IgA1 O-glycopeptide can contain up to six O-glycans.
IgA1 O-glycans are assumed to be core 1 O-glycans.
The number of \textit{N}-acetylhexosamines (N) signifies the number of O-glycosylation sites in the hinge region that are actually occupied with an \textit{N}-acetylgalactosamine (GalNAc) in the glycopeptide.
The number of hexoses (H) represents the number of GalNAcs that have a galactose residue attached to them.

In plasma IgA1, sialic acids (S) are almost exclusively $\alpha2,3$-linked \textit{N}-acetylneuraminic acid (Neu5Ac).
Sialic acids on the O-glycopeptide are therefore assumed to be $\alpha2,3$-linked Neu5Ac, unless the structure contains more sialic acids than galactoses.
In the latter case, additional sialic acids are assumed to be $\alpha2,6$-linked Neu5Ac.
